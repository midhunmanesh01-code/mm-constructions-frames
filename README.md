# M&M Constructions — Cinematic Frames

This repository contains the optimized cinematic frame sequence used by the **M&M Constructions** website.

The frames power the website's scroll-controlled architectural experience, where scrolling through the page controls the progression of a continuous cinematic camera journey.

## 🎬 Frame Sequence

- **Total frames:** 960
- **Resolution:** 2560 × 1440
- **Source frame rate:** 24 FPS
- **Sequence duration:** ~40 seconds
- **Format:** JPEG
- **Optimized sequence size:** ~392 MB
